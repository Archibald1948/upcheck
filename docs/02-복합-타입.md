# 02 — 복합 타입

`internal/config/config.go` 를 옆에 켜 두고 읽으면 좋다.

## struct

필드를 묶은 타입. 클래스는 없고 이것만 있다.

```go
type Monitor struct {
    Name           string
    Target         string
    IntervalSec    int
    Enabled        *bool
}
```

만드는 법:

```go
m := Monitor{Name: "Google", Target: "https://google.com"}   // 필드명 지정 (권장)
m := Monitor{}                                                // 전부 제로값
p := &Monitor{Name: "Google"}                                 // 포인터로 바로
```

필드명 없이 `Monitor{"Google", "https://..."}` 도 되지만 쓰지 않는다.
나중에 필드 순서가 바뀌면 조용히 깨진다.

### 중첩 구조체

```go
type Config struct {
    Workers  int       `yaml:"workers"`
    Monitors []Monitor `yaml:"monitors"`
}
```

`Config` 가 `Monitor` 슬라이스를 품는다. YAML의 구조와 1:1로 대응한다.

### 구조체 태그

백틱 안의 문자열이다. 컴파일러는 그냥 붙여만 두고, 라이브러리가 리플렉션으로 읽는다.

```go
IntervalSec int `yaml:"interval_sec"`
```

태그가 없으면 yaml.v3는 필드명을 소문자로 바꾼 `intervalsec` 를 찾는다.
snake_case 키를 쓰려면 태그가 필수다.

자주 쓰는 옵션:

```go
Name    string `yaml:"name" json:"name"`         // 여러 포맷 동시에
Keyword string `json:"keyword,omitempty"`        // 비어 있으면 출력에서 생략
Secret  string `json:"-"`                        // 직렬화에서 완전히 제외
```

**함정**: 필드가 소문자로 시작하면 리플렉션이 접근할 수 없어서
태그를 붙여도 **조용히 무시된다.** 에러도 안 난다.

### 값 복사

구조체 대입은 **전체 복사**다. 참조가 아니다.

```go
a := Monitor{Name: "A"}
b := a
b.Name = "B"
// a.Name 은 여전히 "A"
```

단, 구조체 안에 slice나 map이 있으면 그것들은 내부적으로 포인터라서
복사본과 원본이 같은 데이터를 가리킨다. (얕은 복사)

## slice

Go에서 "리스트"는 거의 항상 slice다. 배열(`[5]int`)은 길이가 타입의 일부라서
실무에서 직접 쓸 일이 드물다.

```go
var s []Monitor              // nil 슬라이스. len 0, 바로 append 가능
s := []int{1, 2, 3}          // 리터럴
s := make([]Monitor, 0, 10)  // 길이 0, 용량 10
```

### len과 cap

slice는 내부적으로 **(배열 포인터, 길이, 용량)** 세 값짜리 구조체다.

```go
out := make([]Monitor, 0, len(c.Monitors))
for _, m := range c.Monitors {
    if m.IsEnabled() {
        out = append(out, m)
    }
}
```
→ `EnabledMonitors()`

`make` 에 세 번째 인자로 용량을 미리 잡아둔 이유:
`append` 는 용량이 모자라면 **더 큰 배열을 새로 할당하고 전부 복사**한다.
결과 개수를 대충 알고 있으면 미리 잡아두는 게 낫다.
(안 해도 동작은 똑같다. 성능 습관일 뿐이다)

### append의 함정

`append` 는 **새 슬라이스를 반환**한다. 결과를 반드시 다시 대입해야 한다.

```go
append(out, m)        // X 아무 일도 안 일어남 (컴파일 에러로 잡히긴 함)
out = append(out, m)  // O
```

더 고약한 함정: 용량이 남아 있으면 append가 **원본 배열을 덮어쓴다.**

```go
a := []int{1, 2, 3, 4, 5}
b := a[:2]              // [1 2], 하지만 용량은 5
b = append(b, 99)       // a[2] 를 덮어쓴다!
// a == [1 2 99 4 5]
```

슬라이싱한 걸 독립적으로 쓰려면 복사하거나 `a[:2:2]` 처럼 용량을 잘라준다.

### 슬라이싱

```go
s[1:3]    // 인덱스 1,2
s[:3]     // 처음부터 2까지
s[2:]     // 2부터 끝까지
```

문자열도 같은 문법으로 자른다 — 단, 바이트 단위라서 주의가 필요하다(아래).

## map

```go
m := map[string]int{}              // 빈 맵
m := make(map[string]int)          // 같음
m := map[string]int{"a": 1}        // 리터럴

m["b"] = 2
v := m["없는키"]                   // panic 아님! 제로값 0을 준다
v, ok := m["없는키"]               // ok == false — 있는지 확인하는 법
delete(m, "a")
len(m)
```

**`var m map[string]int` 로 선언만 하면 nil 맵이다.** 읽기는 되지만
**쓰면 panic**이 난다. `make` 하거나 리터럴로 만들어야 한다.
(slice는 nil이어도 append가 되는데 map은 다르다 — 헷갈리는 지점)

**순회 순서는 매번 랜덤이다.** Go가 일부러 무작위로 섞는다.
순서에 의존하는 코드를 못 짜게 하려는 의도다. 정렬이 필요하면
키를 슬라이스로 뽑아서 `sort` 해야 한다.

## string, byte, rune

이게 Go에서 처음 헷갈리는 지점이다.

**`string` 은 읽기 전용 UTF-8 바이트 열이다.**

```go
s := "한글"
len(s)          // 6  ← 바이트 수! 글자 수가 아니다 (한글 1자 = 3바이트)
s[0]            // 237 ← byte 하나. 글자가 아니다
```

글자 단위로 다루려면 `[]rune` 으로 변환한다. `rune` 은 유니코드 코드포인트 하나다.

```go
rs := []rune(s)
len(rs)         // 2  ← 글자 수
string(rs[:1])  // "한"
```

그래서 `cmd/upcheck/main.go` 의 `truncate` 가 이렇게 생겼다.

```go
func truncate(s string, n int) string {
    rs := []rune(s)
    if len(rs) <= n {
        return s
    }
    return string(rs[:n-1]) + "…"
}
```

바이트로 잘랐다면 `"한글"[:4]` 이 한글의 3바이트 + 글의 첫 바이트가 되어
깨진 문자(`한�`)가 나왔을 것이다.

`for range` 로 문자열을 돌면 **rune 단위**로 순회한다 (인덱스는 바이트 위치).

```go
for i, r := range "한글" {
    fmt.Println(i, string(r))   // 0 한 / 3 글
}
```

### 문자열 붙이기

`+` 는 매번 새 문자열을 만든다(불변이므로). 반복문 안에서 많이 붙일 거면
`strings.Builder` 를 쓴다.

```go
var b strings.Builder
for _, s := range parts {
    b.WriteString(s)
}
result := b.String()
```

### 자주 쓰는 strings 함수

```go
strings.Contains(body, m.Keyword)      // 포함 여부 ← checker.go 에서 사용
strings.TrimPrefix(path, "/status/")   // 접두사 제거 ← slowserver 에서 사용
strings.Split(s, ",")
strings.Join(parts, ", ")
strings.ToLower(s)
```

## fmt 포맷 동사

```go
fmt.Printf("[%s] %-24s %8v  %s\n", status, name, latency, detail)
```

| 동사 | 의미 |
|------|------|
| `%s` | 문자열 |
| `%d` | 정수 |
| `%v` | 아무 값이나 기본 형식으로 (제일 자주 씀) |
| `%+v` | 구조체를 필드명까지 붙여서 |
| `%q` | 따옴표 붙은 문자열 — 에러 메시지에 값을 넣을 때 유용 |
| `%T` | 타입 이름 |
| `%w` | 에러 감싸기 (`fmt.Errorf` 에서만) |

숫자를 끼우면 폭을 지정한다. `%-24s` 는 왼쪽 정렬 24칸, `%8v` 는 오른쪽 정렬 8칸.

> 참고: 이 폭 지정은 **rune 개수** 기준이라, 한글처럼 터미널에서 두 칸을 차지하는
> 글자가 섞이면 눈으로 볼 때 줄이 어긋난다. 정확히 맞추려면
> `golang.org/x/text/width` 같은 걸로 표시 폭을 계산해야 한다.

출력 함수 구분:
- `fmt.Println` / `fmt.Printf` → 표준 출력
- `fmt.Fprintf(os.Stderr, ...)` → 표준 에러
- `fmt.Sprintf` → 출력하지 않고 **문자열로 반환**
- `fmt.Errorf` → `error` 로 반환
